# Room events

Use room events to give members one clear place for an upcoming game night, meeting, launch, or hangout. Events appear on the room home page and in the room sidebar while they are upcoming.

## Create an event

Room owners and administrators can create events.

<Steps>
  <Step title="Open the room home page">
    Select the room, then open its home page.
  </Step>
  <Step title="Choose Create Event">
    In the Events section, select **Create Event**.
  </Step>
  <Step title="Add the details">
    Give the event a name and start time. You can also add a description, end time, banner image, accent color, and attendee limit.
  </Step>
  <Step title="Set the location">
    Choose a room channel, a custom online location, or an in-person location. Use a channel when the event will happen on Tavrn.
  </Step>
  <Step title="Create the event">
    Select **Create Event**. Members can now find it in the room's Events section.
  </Step>
</Steps>

## Manage an event

Open an event from the room home page or sidebar to view its details. Room owners and administrators can edit it, cancel it, or delete it from the event dialog.

<Note>
  Cancelling an event preserves its record and marks it as cancelled. Deleting it removes it from the room.
</Note>

## Find upcoming events

Upcoming events appear in the **Events** widget on the room home page and the **Events** section of the room sidebar. Select an event to see its time, description, location, and any attendance limit.

## Tips

- Add an end time when the event has a fixed duration.
- Use a channel location for voice hangouts or live chat events.
- Use an all-day event for deadlines, release days, and asynchronous activities.
- Keep the title short so it remains easy to scan in the sidebar.
