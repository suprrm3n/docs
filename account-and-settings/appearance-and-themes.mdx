# Appearance and themes

Tavrn's appearance settings let you choose a color collection, select a light or dark variant, and tune how messages look while you read.

## Choose a theme

Open **Settings → Appearance** to browse theme collections. Each collection has matched light and dark variants built around the same accent color.

Select a theme to preview it, then apply it when you are ready. Your preference is saved to your account.

## Use automatic mode

Some collections support **Auto** mode. Auto follows your device's light or dark appearance while keeping the collection's accent color. Use it when you want Tavrn to switch with your system.

## Make chat easier to read

Appearance settings also include controls for chat readability, including message text size and display density. Increase text size when you want more comfortable reading, or choose a roomier density when you prefer more space between messages.

<Tip>
  Use the live preview in Appearance settings before saving a change. It makes it easier to compare themes and text settings without leaving the page.
</Tip>

## Custom themes

Cocoa subscribers can use the visual theme editor to create a custom theme. Standard themes remain available to every Tavrn member.

## Accessibility

Tavrn includes high-contrast and larger-text options. These are designed to improve readability and are available independently of Cocoa.
